Conditionally remove, customize, or replace WooCommerce "Add to cart" button.

== Description ==

Conditional Add to Cart plugin gives you full control over "Add to cart" button. 
You can **remove**, **customize**, or **replace** the button based on different conditions.

Available conditions:

- Product
- Product category
- Cart content
- Cart quantity
- Cart total
- Cart subtotal
- User country
- User role
- User session status
- and more coming soon...
 
 We constantly add more conditions and actions. If you have any feature request, feel free to post it in [the forum](https://wordpress.org/support/plugin/conditional-add-to-cart). 

== Installation ==

1. Upload `conditional-add-to-cart` to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
